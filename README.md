# 🦁 RemoQwen-MCP v6.0: The Sentinel Lion Edition

**RemoQwen-MCP** is an elite, open-source Model Context Protocol (MCP) server that transforms **Qwen Desktop** into a high-velocity, autonomous Motion Graphics Engineer for **Remotion**.

The **v6.0 Sentinel Lion Edition** introduces a multi-point "Search & Destroy" error hunting engine, ensuring your video logic is bulletproof before you even hit preview.

---

## 🔥 Key Features (v6.0)

- 🦁 **Sentinel Lion Error Hunting:** Unlike standard agents, v6.0 probes multiple strategic points in your video timeline (Start, 25%, 50%, 75%, End) to catch hidden browser-level crashes.
- 🛡️ **Autonomous Self-Healing:** Automatically captures headless browser stack traces and forces the AI into a recovery loop until the code is 100% verified.
- ♾️ **Immortal Connection:** Featuring a low-level SSE heartbeat shield and high-persistence Uvicorn engine to prevent timeouts during complex rendering tasks.
- 🚦 **3 Operational Intensities:** Select your control level via an interactive arrow-key menu:
  - 🚀 **Fully Autonomous:** Total AI freedom.
  - ⚖️ **Guarded Network:** Human-in-the-loop for downloads and commands.
  - 🛡️ **Strict Manual:** Permission required for every single action.
- ⚡ **Parallel-Ready Logic:** Optimized for high-speed sequential validation and real-time terminal monitoring with a cinematic dashboard.

## 🛠️ Quick Start

### 1. Set Up Remotion
```bash
npx create-video@latest
# Choose: Blank template, TailwindCSS (Yes), Skills (Yes)
cd my-video
npm install
npm run dev
```

### 2. Install RemoQwen-MCP
```bash
git clone https://github.com/hse-solutions/RemoQwen-MCP.git
cd RemoQwen-MCP
python -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Configure
Create a `.env` file and set your Remotion project path:
```env
REMOTION_PROJECT_PATH=C:/path/to/your/my-video
```

### 4. Launch the Beast
```bash
python run.py
```
Select your **Intensity Mode**, copy the **SSE URL**, and add it to Qwen Desktop.
